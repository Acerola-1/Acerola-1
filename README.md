## 顺手做的小工具

- [hagimi-monitor](https://github.com/Acerola-1/hagimi-monitor) — 菜单栏里一眼看完 CPU、内存和网络,不占地方
- [Hourcade](https://github.com/Acerola-1/Hourcade) — Steam、Switch、PlayStation 的游玩时长,汇成桌面上的一张卡
- [too-much-chrome](https://github.com/Acerola-1/too-much-chrome) — 查查你的 Mac 里到底装了多少个网页引擎应用
